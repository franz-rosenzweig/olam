<h1 align="center">Olam docs</h1>
<p align="center">How Olam works, from your first lesson to the night you run a game.</p>

These pages explain Olam the way I'd explain it to a friend who's sitting next to me. I'll cover what each screen is for, what the buttons do, and how learning the game and building a world fit together. If you're new, read [What is Olam?](what-is-olam.md) first, which gives you the whole picture in a few minutes, and then [Install](install.md). If you'd like to look around before you install anything, the demo at [stuffs.tiresia.xyz/olam](https://stuffs.tiresia.xyz/olam/) has the lessons and the wiki, with nothing to sign in to.

Basically, the first three pages are for anyone, the middle ones are for using it, and the last two groups are for running your own copy and changing the code.
